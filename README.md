# CoolWheels — MVP Validation Package

Everything Group 5 needs to run a lightweight MVP test before the coaching session.

## What's inside
- `index.html` — a self-contained landing page (open it directly in a browser,
  or upload the whole `coolwheels/` folder to any static host: GitHub Pages,
  Netlify, or Carrd's "import" option). Uses `assets/hero.jpg`, the concept
  render already generated.
- `assets/hero.jpg` — the CoolWheels concept image used on the landing page.
- `idea_card_v2.md` — the updated Idea Card, now including solar power,
  device charging, and an optional long-term micro-workspace tier.
- `survey_questions.md` — a ready-to-paste survey for Google Forms, Tally,
  or Typeform.

## Before you publish the landing page
1. Open `index.html` in a text editor and replace
   `REPLACE-WITH-GROUP-EMAIL@example.com` in the form's `action` attribute
   with a real group inbox, or swap that `<form>` block for an embedded
   Tally/Typeform/Google Form link instead — a plain `mailto:` form is a
   placeholder, not a reliable way to collect responses.
2. To host it for free: create a GitHub repository, add these files, then
   enable GitHub Pages (Settings → Pages → deploy from main branch) — this
   gives you a public link to include in your Project Coach submission.
   Alternatively, drag the folder into Netlify Drop (netlify.com/drop) for
   an instant link with no account needed.

## Suggested next steps
1. Send `survey_questions.md` out via Google Forms to a small group of
   wheelchair users or disability-services contacts (aim for signal, not
   volume — even 10–15 responses is useful at this stage).
2. Publish `index.html` and share the link alongside the survey to gauge
   interest (page visits, form fills).
3. Bring both the qualitative survey answers and the landing-page
   engagement numbers to the Project Coach meeting as early validation
   evidence for the Build–Measure–Learn loop.
